# `KMP` 题目

## 题目描述

已知字符串 $s$ 是由某个字符串 $s^*$ “自我拼接” 数次形成，给定字符串 $s$ ，求最短的 $s^*$ 长度。
> 例如：$s="abababa"$ 是由 $s^*="ab"$ “自我拼接” 而成

## 输入格式

* 第 1 行 $N$ 表示 $N$ 个 $s$
* 第 $i+1$ 行表示第 $i$ 个字符串 $s_i$
> * 保证每个 $s_i$ 都对应一个 $s_i^*$
> * 字符串长度为 $M$

## 输出格式

* 输出 $N$ 行
* 第 $i$ 行表示第 $i$ 个字符串 $s_i$ 对应的 $s_i^*$ 长度

## 输入输出样例

### 输入样例 #1
```markdown
5
ababababababababa
ereereereereer
abcdabcdabcd
abaabaabaaba
asdfasdf
```

### 输出样例 #1
```markdown
2
3
4
a
4
```

## 说明/提示
* 样例#1中的第一个字符串 `ababababababababa` 有 `ab`, `abab`, `abababab` 可以作为 $s^*$ 的备选，其中 `ab` 最短，故答案为 2

## 规模

$$
N = 5 \\
1 \le M \le 10^7
$$

## 限时
测试平台限时1s。  
注意，每个人设备不同，不一定能在1s内完成运算。  
在修改代码时，只完成```solve```函数，运用KMP算法，以O(M)复杂度遍历```a```并维护```nxt```数组，最后给ans赋合适的值，即可满足时间要求。
在现有main.cpp的基础上不需要管理输入输出和内存。  
> Tips: 现有的```memset```和```scanf```也是能满足显示要求的关键。
